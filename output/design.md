# Problem 10: Campus Customs Design & Styling

## 1. Typography & Hierarchy

**Changes:** Added clean modern font pairings using Manrope for interface text and Georgia accents for editorial emphasis. The palette now uses Yale Blue `#00356b`, White `#ffffff`, Silver `#d8e1ea`, and a restrained Yale gold `#bd9b60`. Eyebrow labels, oversized headings, and clear price treatments create a deliberate information hierarchy.

**Impact:** Enhances readability and makes product names, prices, and details instantly scannable while giving the storefront a recognizable point of view.

## 2. Product Presentation & Motion

**Changes:** Product cards use generous image space, soft warm backgrounds, subtle shadows, and smooth hover zoom transitions. Product details are presented in a spacious two-column layout with clear stock and size pills.

**Impact:** Increases visual engagement and encourages shoppers to explore product details without making the interface feel busy.

## 3. Storefront Chat Interface

**Changes:** Styled the floating chat entry point and concierge header in Yale Blue, with white chat surfaces, silver supporting backgrounds, distinct user and agent bubbles, suggestion chips, and an animated typing indicator.

**Impact:** Builds shopper trust, makes conversational discovery approachable, and gives visible feedback while the agent is working.

## 4. Motion and responsive polish

**Changes:** Added page-load fade-in, button hover lift, accessible focus states, and responsive card/detail layouts for smaller screens.

**Impact:** Makes the site feel responsive and finished across devices, helping shoppers stay oriented while browsing and moving between product views.
